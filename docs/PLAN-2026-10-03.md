- Real fixtures, cut from the 2026-10-03 bulk files (`~/.cache/tcg-oracle-searcher/` has the full files):
  - `tests/fixtures/oracle_cards_sample.jsonl`: 58 cards covering every layout, the Jace cards, Ral, Valki, previews, game changers, split, adventure, MDFC, tokens, an emblem, an art card;
  - `tests/fixtures/oracle_tags_sample.jsonl`: the 386 tags that touch them, plus ancestors;
  - `tests/fixtures/purroxy_queries.txt`: 39 real queries Purroxy sends.
- **Search API** (orange builds it, grey's Lambda handler calls it):
  ```python
  search(conn, q: str, order: str = "edhrec", dir: str = "auto", page: int = 1, page_size: int = 175) -> SearchResult
  # SearchResult: data (list of card dicts from card_json), has_more (bool), total_cards (int)
  # raises Unsupported(reason) when the query can't be answered exactly; never a partial or guessed answer
  ```

## 🟢 Green: importer (`oracle_searcher/importer.py`)
- `build(cards_path, tags_path, out_path) -> dict` (stats): streams gzipped or plain JSONL and writes the SQLite file per `schema.py`. It writes to `out_path + ".tmp"` and renames at the end, so a failed build never leaves a half file.
- **Reuse Sylvan's `api/card_processing.py`** (type parsing, rarity, mana dict, devotion, is: tags) rather than rewriting it. Read how Sylvan's import fills each column (`api/card_processing.py`, `api/db/`) and match it, with the multi-face rules from `schema.py`.
- **`is_extra`:** decide which layouts and types Scryfall's search hides by default. Check it against Scryfall itself (see "Scryfall calls" below), and record the evidence in a test docstring.
- **`card_json`:** the Scryfall object trimmed of fields no caller needs (multiverse/mtgo/arena/tcgplayer/cardmarket ids, `*_uri` fields except `image_uris`, `purchase_uris` and `scryfall_uri`). Keep `card_faces`, `all_parts`, `prices`, `legalities`, `image_uris` and `edhrec_rank`. Report the size before and after.
- **Oracle tags:** `card_oracle_tags` holds each tagged card's tag slugs plus every ancestor's slug (`parent_ids`, transitively).
- **`check(db_path) -> list[str]`:** problems found (empty means good). Card count over 30,000 for a full file, known cards present, every multi-face card has faces. It runs before a build is published.
- **CLI:** `python -m oracle_searcher.importer --cards X --tags Y --out Z`.
- **Tests (fixtures only):**
  - Jace, Vryn's Prodigy has Creature and Planeswalker in `card_types`, both faces' text in `oracle_text`, and face 2 with loyalty 5;
  - Valki (MDFC), Heaven // Earth (split) and Gollum (adventure) map correctly;
  - colour, identity and produced masks;
  - legalities;
  - the preview card is present;
  - `game_changer`;
  - tag ancestors;
  - `is_extra`;
  - the atomic rename (a failed build leaves no file);
  - `check` failures.
- **Then a full-file build:** report the time, peak memory, the SQLite size, and the gzipped size.

## 🟠 Orange: compiler and search (`oracle_searcher/sqlite_compiler.py`, `oracle_searcher/search.py`)
- **Parse with Sylvan's hand parser** (`api.parsing.parse_scryfall_query`), then compile its tree to a parameterised SQLite `WHERE` clause over `schema.py`. Write it as a separate compiler that walks the nodes; Sylvan's `to_sql` methods (PostgreSQL) are only a reference.
- **Any node, attribute or operator not handled exactly raises `Unsupported`.** Cover Purroxy's corpus (`tests/fixtures/purroxy_queries.txt`) first, then the rest in order of use.
- **Multi-face rules** from `schema.py`; numeric attributes check `card_faces` with `EXISTS`.
- **Regex** through a registered `REGEXP` function (Python `re`, with Sylvan's regex budget).
- **Colour logic:** colour and identity comparisons (`c:`, `id<=`, `c>=`, `c=`, colourless, multicolour) on the masks, matching Scryfall.
- **Hide `is_extra` rows** unless the query asks for them (as Scryfall does: `include:extras`, `t:token`, and so on; confirm with Scryfall).
- **Ordering:** `edhrec` (rank ascending, unranked last), `released`, `name`, `cmc`, `usd`, with `dir=auto|asc|desc` exactly as Scryfall's docs define each default. Paging: `page_size` 175, `has_more`, `total_cards`.
- **Tests:** build a small database in each test from the fixture cards. Until green's importer is merged, insert rows with a test helper that fills only the columns a test needs; grey switches these to the real importer at merge.
  - every query in Purroxy's corpus compiles, or raises `Unsupported` with a reason;
  - each operator family;
  - multi-face matches (`o:` text found only on a back face, `t:planeswalker` finding Jace, Vryn's Prodigy, loyalty on a face);
  - ordering and paging;
  - extras hidden.

## Scryfall calls (both lanes)
To check a behaviour against Scryfall, call `https://api.scryfall.com/cards/search` at most once a second, with a `User-Agent: tcg-oracle-searcher/0.1` and `Accept: application/json` header. Save each response you rely on under `tests/fixtures/scryfall/` and cite it in the test. Never call Scryfall from a test.
